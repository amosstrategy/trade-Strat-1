# Fringe Research Skill

Recherche-Methodik für vergrabene, nicht-mainstream wissenschaftliche Evidenz zu
Fringe-/Paranormal-/Bewusstseins-Themen. Fünfsprachig (EN/DE/ES/PT/RU), Antwort auf Deutsch.

## Kern
- Evidenz-Ampel: 🟢 BELEGT / 🟡 UMSTRITTEN / 🟠 GRAU / 🔴 WIDERLEGT / ⚪ SPEKULATION
- Immer Abstract gegen Volltext prüfen (Ergebnisse weichen oft ab)
- Reputation nennen, auch qualifizierte Quereinsteiger
- Keine Gegenargumente = Warnsignal, nicht Stärke
- Kein Wikipedia/Listicle, nur Primärquellen + regionale Repositorien

## Installation
Settings → Customize → Skills → "+" → Create skill → dieses ZIP hochladen.
Braucht Web-Suche + Code Execution aktiviert.
